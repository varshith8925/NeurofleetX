# NeuroFleetX

NeuroFleetX is a full-stack urban mobility and fleet management system built with:

- React + Vite frontend
- Spring Boot + JWT backend
- MySQL persistence layer
- Flask route optimization service

- [`neurofleet`](/C:/Users/LSW/Desktop/Infosys_internship/neurofleet): Vite frontend
- [`neurofleet-backend`](/C:/Users/LSW/Desktop/Infosys_internship/neurofleet-backend): Spring Boot API
- [`ai-service`](/C:/Users/LSW/Desktop/Infosys_internship/ai-service): Flask AI route optimizer
- [`database`](/C:/Users/LSW/Desktop/Infosys_internship/database): MySQL schema

## Core capabilities

- JWT authentication with `ADMIN`, `FLEET_MANAGER`, `DRIVER`, and `CUSTOMER`
- Vehicle CRUD and driver assignment
- Telemetry capture plus scheduled backend telemetry simulation
- Maintenance planning and alerts
- Customer booking flow with backend-powered vehicle recommendations
- Driver ride acceptance and completion flow
- Route optimization through Flask, persisted in MySQL through Spring Boot
- Role-specific dashboards with maps and analytics
